## Исправления, найденные при проверке

- CLI-движок 0.3.0 не загружал settings.json: существующие переключатели не управляли очисткой. Теперь поддерживаемые категории, возраст файлов, Safari, MobileSync и внешние команды учитывают настройки.
- Dry-run создавал незавершённый запуск в истории. Теперь журнал создаётся только после подтверждения настоящей очистки.
- Пересекающиеся корни могли дважды считать и удалять один набор файлов. Кандидаты дедуплицируются.
- Ошибки внешних команд не влияли на результат. Теперь учитываются в статусе.
- Убран безусловный останов всех симуляторов Xcode.
- Не реализованные ранее категории не расширены без проверки. В настройках они отключены и отмечены «позже»: временные файлы, часть AI/ML, Podman. История и замер места пока обязательны, их прежние неработающие переключатели тоже недоступны.
- Настройки Homebrew cleanup применяются консервативно: полный cleanup выполняется только при включении старых версий, кэша и временных сборок; autoremove управляется отдельно.

## Ограничения

Карта показывает сумму логических размеров файлов, а не обещание освобождения такого объёма. Ссылки не обходятся, отдельные тома выбираются отдельно; ограничения доступа macOS отображаются как неполный результат. На диаграмме до 180 крупнейших объектов, в списке все непосредственные дочерние объекты. Содержимое файлов не читается для построения карты.

Обновление запрашивается вручную: manifest из публичного репозитория, HTTPS, проверка источника, версии ОС и SHA-256, открытие DMG. Установка выполняется пользователем через Finder. Локальная ad-hoc подпись не заменяет Developer ID и нотариализацию Apple.
