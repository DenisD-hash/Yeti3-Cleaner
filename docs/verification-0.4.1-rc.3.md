# Предрелиз 0.4.1-rc.3

Уточнение реального времени: сканер отправляет каждое полученное значение размера и метаданных немедленно через `entryProgress`. Нет ожидания 64 объектов или таймера 150 мс. `LiveScan` хранит последние значения и допускает только одну ожидающую задачу интерфейса, чтобы быстрый диск не перегружал очередь устаревшими перерисовками. Окно перерисовывается, когда главный цикл интерфейса готов обработать данные. Ограничение раз в две секунды относится только к записи SQLite.

ScannerTests отдельно проверяет: первый прочитанный файл передаётся до чтения следующего; отмена из этого обработчика прерывает обход. Также прошли 27 Rust-тестов, сборка Universal с `-D warnings` и интеграционная очистка только во временном HOME.

Снимки SQLite и единые настройки включены из rc.2: [проверки](verification-0.4.1-rc.2.md).
Поддержка старых ОС/PowerPC остаётся незавершённой. Визуальная проверка интерфейса не выполнена из-за отсутствия доступа Computer Use.
