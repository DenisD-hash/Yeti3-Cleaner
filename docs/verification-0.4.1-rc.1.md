## Classic PowerPC

Retro68 собрал отдельный экспериментальный просмотрщик каталогов для PowerPC, с `-mcpu=601`: PEF/MacBinary/HFS image.
Он считает data/resource forks и строит карту по частям через цикл событий. Это исходный прототип: до 256 объектов в открытой папке и 128 уровней, только текущий том, нет очистки, настроек и обновлений. При достижении ограничений результат неполный.
Запуск на PowerPC или эмуляторе НЕ проверен. Соответствие System 7.1.2, другим Classic Mac OS и конкретным моделям НЕ подтверждено.

## Оставшаяся совместимость

Требование охватывает Classic Mac OS от первого PowerPC, все выпуски OS X для PowerPC, ранние Intel (включая 32-битные), современные Intel и Apple Silicon.
Сейчас готова современная universal-сборка и компилируемый прототип Classic. Порты для PowerPC OS X 10.0–10.5, Intel OS X 10.4–macOS 13 и Apple Silicon macOS 11–13 не готовы. Называть этот предрелиз поддерживающим всё железо/ОС нельзя.
