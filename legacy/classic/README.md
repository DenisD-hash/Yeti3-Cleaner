# Classic PowerPC — экспериментальный прототип

Сборка: `bash legacy/classic/build.sh` (Docker + Retro68). Целевой CPU: PowerPC 601.
Результат: `target/classic-ppc/Yeti3Classic.bin` (MacBinary с ресурсами) и `.dsk` (HFS).
Не переносите `.APPL` обычным копированием между файловыми системами без resource fork.

Это отдельный просмотрщик каталогов с частичным построением диаграммы и детализацией.
Он ничего не удаляет. Поддержка всех Classic Mac OS пока не подтверждена запуском.
Ограничения: 256 объектов открытой папки, 128 уровней, текущий том, английский интерфейс;
нет управления очисткой, пресетов, SQLite и сетевого обновления. Это не готовая замена современному Cleaner.
Нужны проверка на System 7.1.2/PowerPC 601 и следующих системах, устранение ограничений,
портирование функций и отдельные реализации для PowerPC OS X и ранних Intel/Apple Silicon.

Retro68: https://github.com/autc04/Retro68 (в образе используются Multiversal Interfaces).
